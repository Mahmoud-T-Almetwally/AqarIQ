# AqarIQ — Project Description

### **Project Overview**

A production-grade, AI-driven real estate platform tailored for the Egyptian market (Primary & Resale). It ingests data from major Egyptian portals (Aqarmap, PropertyFinder) and features an advanced LLM chatbot capable of generating customized charts, market reports, and dynamic surveys (outputting frontend UI data, not generating images) based on natural language queries.
